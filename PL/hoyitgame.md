# 코드분석
### BottomTray
역할 : 하단에서 과일 ui를 보여주고 맞춘항목에 ✓ 표시를 해줌
코드 분석
    - 카드게임 맞을 시 1 아니면 0
    - 정답인 상태일시 투명도 줘서 흐려짐

### DifficultyCard
역할 : 게임 들어갔을때 난이도 설정하는 난이도 설정 컴포넌트
코드 분석
    - 카드 관련한 ui코드임
    - 카드 클릭시 배경색 하얀색 -> 파란색으로 변경, 글자색 해당 칸안에 전부 하얀색
    - 카드 클릭시 박스에 ✓ 표시

### MemoryBoard
역할 : 카드 뒤집기, 목숨
코드 분석
    - 애니메이션 중 클릭을 방지했음
    - 이미 짝이 맞춰진 카드에 값을 줘서 중복 클릭을 방지함
    - 카드 뒤집기 애니매이션
    - 첫번째 카드 뒤집기와 두번째 카드 뒤집기의 코드를 다르게하고 판정을 두번째 카드 뒤집기를 한 후로 바꿔서 버그를 방지함
    - 매칭 성공코드
    - 매칭 실패시 카드 다시 뒤집음
    - 카드 뒤집기 원리 : y축 회전 + opacity

### MemoryTile
역할 : 카드 앞면 ui 컴포넌트
코드 분석
    - 카드 앞면을 구현한 코드임
    - 카드 이미지 수정하려면 여기서 수정하면 됨

### PlayHeader
역할 : 플레이 상단 표시
코드 분석
    - 뒤로가기 버튼 터치(터치시 투명도)
    - 목숨 표시 + 목숨 줄어들고 늘어나는거
    - 현재 난이도
### ResultOverlay
역할 : 모달창
코드 분석
    - 게임 결과를 나타내는 모달창
    - 성공 여부
    - 성공 실패 상태 나타냄
    - 다시하기
