## 세부 내용

### useQuery
- useQuery란 무엇인가?
 - 가장 기본적인 쿼리 훅으로, 컴포넌트에서 데이터를 가져올 때 사용한다.
---
### queryKey
- QueryKey란 무엇인가?
 - 쿼리를 식별하는 고유한 값으로, 배열 형태로 지정함
 - 다중 아이템 쿼리 키를 사용할 때는, 아이템의 순서가 중요함
 - 기본적으로 쿼리 함수에서 사용하는 변수는 쿼리 키에 포함되야함(변수가 변경될 때 자동으로 가져오기 위함))
 - 변수와 상관없이 항상 하나의 쿼리로 처리하고 싶다면 ESLint exhaustive-deps 규칙 비활성화 가능
 - 프로젝트 전체에서 규칙을 비활성화할 수도 있음
---
### queryFn
- queryFn란 무엇인가?
 - 데이터를 가져오는 비동기 함수
 - 꼭 데이터를 반환하거나 오류를 던져야함
 - 던져진 오류는 반환되는 error 객채로 확인 가능
 - error은 기본적으로 null
---
### select
- select란 무엇인가?
 - 가져온 데이터를 변형 할 수 있게하는거
 - 쿼리 함수에서 반환하는 데이터를 인수로 받음 -> 선택 함수에서 처리 -> 반환 이러면 최종데이터가 됨
 - 최종 데이터의 타입은 useQuery의 3번째 제너릭 타입으로 선언 가능
 - 2번째는 오류 타입(Error)이다.
 - 쿼리 함수를 따로 선언해 제공시 선택 함수를 통한 최종 데이터의 타입 추론 가능
---
### placeholderData
- placeholderData란 무엇인가
 - 새로운 데이터를 가져오기 직전의 이전 데이터를 받을 수 있는 함수를 지정하여 반환해 임시 데이터로 사용할 수 있게함
 - 새로운 데이터를 가져오는 과정 = 쿼리가 무효화되어 일시적으로 데이터가 없음 = (undefined)가 되면 데이터 출력 화면이 깜빡일 수 있음 <- 이를 방지하기 위해 placeholderData 옵션을 사용하면 쿼리 함수가 호출되는 대기 상태에서 임시로 표시할 데이터를 미리 지정 가능
---
### structuralSharing
- structuralSharing이란 무엇인가
 - 새로운 데이터를 가져올 때 이전 데이터와 비교해 변경되지않은 부분은 이전 데이터를 재사용할 수 있음 <- 메모리 사용량 최적화 및 불필요한 리렌더링 방지
  - 데이터가 항상 새로은 참조여야 하거나 데이터가 단순해 깊은 비교가 필요하지 않은 경우에도 false로 지정하는 게 좋음
---
### meta
- meta란 무엇인가
 - 쿼리에 대한 추가 정보
 - ex) 쿼리 함수에서 발생한 오류 메세지 출력을 전역으로 처리
---
### isFetching
- isFetching이란 무엇인가
 - 쿼리 함수가 실행 중인지의 여부로, 데이터를 가져오는 중을 나타냄
 - 캐시된 데이터가 없고 쿼리가 아직 완료되지 않은 상태의 여부로, initialData혹은 placeholderData 옵션으로 데이터를 제공하면 출력대기가 필요하지 않으므로 false를 반환함
 - enabled 옵션을 false로 지정하면 쿼리가 대기 상태 시작이므로 true를 반환함
 ---
### isLoading
 - isLoading은 isFetching 과 isPending와 같은 의미로, 쿼리의 첫 번째 가져오기가 진행 중인 경우를 나타냄
---
### refetch
 - 데이터를 항상 새롭게 다시 가져올 수 있다.
 - 신선도를 기반으로 데이터를 가져오려면 queryClient.fetchQuery()메서드를 사용할 수 있다
 - 캐시된 데이터가 필요하다면 queryClient.getQueryData() 메소드를 사용할 수 있다
 - 캐시된 데이터가 없는 경우 undefined를 반환
 - useQueryClient 훅을 사용해 queryClient 객체를 가져온 후 getQueryData 메소드를 사용함
---
### uselnfiniteQuery
- 더보기 버튼으로 추가 데이터를 더 가져오거나 더 나아가 무한 스크를 기능을 찾아볼 수있는 UI이다. 
- TanStack Query에서 제공함
---
### useMutation
-  TanStack Query에서 제공하는 데이터 변경작업(생성, 수정, 삭제)를 위한 훅
- 데이터 변경 작업 처리 및 성공, 실패, 로딩 등의 상태를 얻을 수 있음
- 쿼리와 차이점이 무엇이냐 쿼리는 가져오기에 집중하고 변이는 보내기에 집중함
---
